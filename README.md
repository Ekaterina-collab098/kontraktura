# Контрактура

Помощник государственного заказчика для подготовки проекта описания объекта закупки по 44-ФЗ и КТРУ. Приложение хранит локальное зеркало каталога в SQLite, сохраняет все редакции карточек и рассчитывает обязательность их применения на выбранную дату.

## Запуск

Требуется Node.js 24. Внешние npm-пакеты не используются.

```powershell
npm.cmd start
```

Откройте `http://127.0.0.1:4173`. При первом запуске создается `data/ktru.sqlite` и загружаются три явно помеченные демонстрационные карточки.

## Публичная версия

Production: https://kontraktura.vercel.app/ . Пользовательский вход не требуется. На Vercel каталог хранится в памяти серверной функции: демонстрационные карточки загружаются при холодном старте, а результаты публичного поиска ЕИС доступны на время жизни экземпляра функции. Данные, добавленные через административный импорт, там не сохраняются между холодными стартами; для постоянного зеркала нужна внешняя база данных. Административные API на Vercel отключены без `KTRU_ADMIN_TOKEN`.

## Возможности

- поиск по названию товара, ОКПД2 и КТРУ;
- разделение обязательных и дополнительных характеристик;
- редактирование значений и обоснований дополнительных требований;
- предварительная проверка комплектности;
- копирование проекта описания и печать в PDF;
- ссылки на применимые нормы и официальный каталог ЕИС.

## Подключение официальной выгрузки ЕИС

ЕИС меняет публичные адреса и в отдельных контурах предоставляет интеграционные ресурсы после регистрации. Поэтому URL не зашит в код. Получите действующий HTTPS-адрес выгрузки КТРУ в вашем официальном контуре ЕИС и передайте его через `KTRU_FEED_URL`:

```powershell
$env:KTRU_FEED_URL = "https://<официальный-хост>.zakupki.gov.ru/<путь-к-выгрузке>"
$env:KTRU_ADMIN_TOKEN = "сгенерированный-длинный-секрет"
$env:KTRU_SYNC_HOURS = "24"
npm.cmd start
```

Сервис принимает удаленные выгрузки только с `zakupki.gov.ru` и его поддоменов, только по HTTPS. Поддерживаются JSON, XML, ZIP и GZIP. Синхронизация выполняется при запуске и далее через заданное число часов.

Запуск синхронизации вручную:

```powershell
Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:4173/api/admin/sync" `
  -Headers @{ Authorization = "Bearer $env:KTRU_ADMIN_TOKEN" }
```

## Импорт файла ЕИС

Если прямой feed URL недоступен, скачайте официальную выгрузку КТРУ из ЕИС и импортируйте ее локально:

```powershell
npm.cmd run import -- "C:\Выгрузки\ktru.zip"
```

Или через административный API:

```powershell
Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:4173/api/admin/import?filename=ktru.zip" `
  -Headers @{ Authorization = "Bearer $env:KTRU_ADMIN_TOKEN" } `
  -ContentType "application/octet-stream" `
  -InFile "C:\Выгрузки\ktru.zip"
```

Без `KTRU_ADMIN_TOKEN` административные операции разрешены только с loopback-интерфейса. При публикации сервиса в сети токен обязателен.

## Редакции и даты

- Карточка идентифицируется кодом КТРУ.
- Нормализованное содержимое подписывается SHA-256.
- Неизменившаяся карточка не создает новую редакцию.
- Изменение создает неизменяемую редакцию, предыдущая остается в истории.
- Для выбранной даты проверяются начало действия, дата обязательного применения и окончание действия редакции.
- Если дата отсутствует в источнике, интерфейс показывает неопределенный статус, а не делает предположение.

## Формат нормализованного JSON

Для интеграции с корпоративной шиной можно передавать массив или объект с полем `items`:

```json
{
  "items": [
    {
      "code": "00.00.00.000-00000000",
      "okpd2": "00.00.00.000",
      "name": "Наименование позиции",
      "validFrom": "2026-01-01",
      "mandatoryFrom": "2026-02-01",
      "validTo": null,
      "sourceUpdatedAt": "2026-01-15T10:00:00Z",
      "required": [
        { "name": "Характеристика", "type": "text", "value": "Значение", "unit": "шт" }
      ]
    }
  ]
}
```

XML-адаптер распознает распространенные имена полей ЕИС с XML namespaces. При изменении XSD ЕИС адаптер следует обновить и проверить на контрольной выгрузке до промышленного импорта.

## Переменные окружения

- `PORT` — порт, по умолчанию `4173`.
- `HOST` — адрес прослушивания, по умолчанию только `127.0.0.1`.
- `KTRU_DATABASE` — путь к SQLite.
- `KTRU_FEED_URL` — официальный адрес выгрузки ЕИС.
- `KTRU_ADMIN_TOKEN` — токен административных API.
- `KTRU_SYNC_HOURS` — период синхронизации, по умолчанию 24 часа.

## Юридически значимые ограничения

Сам факт успешного импорта не делает сторонний файл официальным. Используйте только выгрузку, полученную из ЕИС, контролируйте журнал синхронизации и сопоставляйте контрольные карточки с сайтом ЕИС. Перед размещением закупки дополнительно проверяются статья 33 44-ФЗ, правила использования КТРУ по постановлению Правительства РФ № 145, нормирование и национальный режим.
